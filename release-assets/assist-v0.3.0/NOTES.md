# AssistStructure Lab 0.3.0

手机画面与页面结构同时监看；不使用无障碍、USB 调试或 Root。

- Android 14+ APK：增加 MediaProjection 实时屏幕共享，适配横竖屏变化；每次开始由用户在系统弹窗授权。
- Windows x64 EXE：左侧画面、右侧结构树，显示实际接收 fps，可选叠加控件边界，支持节点详情、暂停刷新和 JSON 导出。
- 结构默认目标间隔从每帧完成后等 1 秒，改为包含采集耗时的 200 ms；可选 100 / 200 / 500 / 1000 ms，请求串行，不积压。
- 画面预设：长边 720 / 目标 15 fps、960 / 目标 10 fps（默认）、1280 / 目标 10 fps。实际速度受手机、页面和 Wi-Fi 影响；静止画面可能不产生新图像。
- 前台服务持续通知、可拖动悬浮控制窗；通知、悬浮窗和 App 均可停止。提供通知、悬浮窗、电池优化和应用后台设置入口。
- 结构 UDP 38583 自动发现；画面 TCP 38584 仅连接选中的手机，最多同时支持两台电脑，自动重连、仅保留最新待处理帧。

## 使用

1. APK 可覆盖旧测试版安装（签名保持一致），电脑换用本版 EXE；无需安装 Python。
2. 手机和电脑在同一 IPv4 局域网，电脑允许程序通过专用网络防火墙。
3. 手机仍设为默认数字助理，允许通知；需要悬浮窗时先授予悬浮窗权限。
4. 点击“开始实时画面与结构共享”，授权整个屏幕，然后切换到目标 App。
5. 小米可在系统设置允许后台运行 / 自启动，并在最近任务中锁定 App；菜单名称随 HyperOS 版本变化。

画面与结构独立采集，时间可能有差异。传输未加密，同网段设备可接收；不上传互联网，不保存录像。受保护页面可能黑屏；锁屏或系统撤销屏幕共享后可能需要重新授权。前台服务和悬浮窗不能保证进程永不被系统结束。
