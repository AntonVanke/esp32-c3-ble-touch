ESP32-C3 / BLUETOOTH HID

让触摸，走蓝牙。

用一块 C3 测试 Android 的外接触摸输入。直接看手机，无需 USB 调试或无障碍权限。

单机验证 · 两点触摸
当前浏览器不支持 Web Serial。请在电脑端 Chrome 或 Edge 中打开此 HTTPS 页面。
01

烧录 C3

用数据线将开发板接到电脑，选择板子的 USB 类型。

请使用支持 Web Serial 的电脑浏览器。烧录需要 HTTPS 或 localhost。

固件适用于 4 MB Flash 的 ESP32-C3。安装会替换板内固件；烧录时可选择是否擦除数据。

无法连接或烧录后没有串口？

按住 BOOT，轻按 RESET 后松开 BOOT，再尝试烧录。原生 USB 板烧录后按一下 RESET；关闭烧录弹窗，再连接下方控制台。若端口仍被占用，拔插一次 USB。CH340 / CP210x 板请选择“USB 转串口”版本。

02

连接控制台与手机

先连接板子的串口，再在手机蓝牙设置中配对 C3。

03

在手机上观察

用手机浏览器打开测试靶页，查看落点、轨迹、触点数和输入类型。

打开手机测试靶页 ↗

出现 touch 表示浏览器收到触摸事件。蓝牙连接成功本身不代表手机已正确识别触摸屏。
